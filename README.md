# dsh-plugin-tiles · 插件方块

**一排小方块**：**一个方块 = 一个装过的插件**。左键开关，右键改名，尺寸可调。

## 安装

需要 DSH 0.2.1 及以上。

```sh
dsh plugin add dsh-plugin-tiles
```

还没发 npm 的话，直接从仓库装：

```sh
dsh plugin add git+https://github.com/zydxn77/dsh-plugin-tiles.git
```

装完**重启 DSH** —— 客户端插件没有热重载。

它挂在框架浮层上，位置由插件自己量：

- **会话里**：贴在「对话 / 轨迹 / 上下文 / 编队」那一栏的右侧空白里；
- **新对话页**（还没有会话）：那一栏不存在，改贴输入框卡片下沿、同宽居中。

> 位置是靠量 DOM 算出来的，不是官方槽位 —— DSH 没给标签行留座位。
> 换 DSH 版本后如果它跑到别处去了，先来这里看 `docs/NOTES.md` 的「为什么是浮层」。

## 使用

| 操作 | 效果 |
|---|---|
| **左键**方块 | 开 / 关这个插件 |
| **右键**方块或抽屉里的行 | 改名（留空 = 用原名） |
| 点末尾的 **`▾`** | 打开抽屉：全部插件 + **里模式** + 尺寸滑块 + 「全部静音」 |
| 抽屉里的 **`里模式`** | 连系统自带的也列出来。**只能看，不能关** —— 关错了 DSH 起不来 |
| 抽屉里的 **`全部静音`** | 关掉所有开着的第三方插件，记下当时开着哪些；再点一下只把这些开回来 |
| 鼠标停在方块上滚轮 | 调大小（14–44） |
| `Shift` + 滚轮 | 调长短（宽度 12–96） |
| 悬停 | 看完整名字、包名、当前状态 |

- 只摆 **9 块**，其余收进 `▾` 抽屉；
- 尺寸和名字都记得住：尺寸存浏览器（`localStorage`），名字存宿主
  （`$DSH_HOME/plugin-tiles/names.json`），换浏览器不丢。

### 改了什么时候生效

外壳这一层（宿主插件）多数当场生效；**客户端插件要重启 DSH**。
宿主回 `restart-required` 的那一条，抽屉里会在行尾标 **`待重启`**，底部写一行
「有 N 项改过了，重启 DSH 才真正生效」。所以这个面板同时也是**启动清单**：
在这儿勾好，重启之后按它加载。

## 它不显示什么

- **DSH 自带的插件** —— 默认不摆；要看得开「里模式」，但那些**只读**；
- **改不了的条目**（`readOnlyReason` 非空）—— 点了也没用；
- **它自己**不能关自己（关掉这排就没了），要关请走「设置 → 插件」。

## 全部静音

抽屉右上角那颗按钮：按一下关掉**所有开着的**第三方插件并把名单记进
`$DSH_HOME/plugin-tiles/mute.json`；再按一下（变成「恢复 N 个」）只把名单里那些开回来。

静音状态下再点会被拒（409 `already-muted`）—— 再关一次会用新名单冲掉原名单。

## 卸载

```sh
dsh plugin remove dsh-plugin-tiles
```
